# It-Depends

This project is built for educational purposes only. The intention is to create an interactive web app (built with R Shiny) where students can visualize and simulate complex epidemiological biases during their learning.

There are many possible biases in epidemiological studies, and the same type of bias is often referred to by different names. While this tool does not exhaustively cover every potential bias, the visualizations and simulations have been curated to present the biases commonly discussed in the field.

This project is open to further enrichment, including but not limited to new content, varied examples, innovative visualizations, and UI/UX improvements. 

**Disclaimer:** The code for this interactive web tool was written using Google Gemini based on the author's epidemiological specifications.
